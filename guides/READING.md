# 読み方と表示環境

[連載目次へ](../README.md)

## GitHubのMarkdownで読む

リポジトリのREADMEから各回を開き、Preview表示を使う。RawやCode表示は原稿テキストを見るためのものである。各回の冒頭と末尾に、前回・目次・次回のリンクがある。

## HTMLで読む

GitHub Pagesが有効なら、公開URLのトップページが目次になる。手元で再生成した場合は `_site/index.html` をブラウザで開く。サーバー起動は不要である。全10回を一つのファイルで読む場合は `_site/complete.html` を開く。どちらも外部通信をしない。

## 再生成する

Python 3.11以降とPandoc 3.xを使う。Python標準ライブラリだけを使うため、pipによる追加導入は不要である。Pandocの導入方法は[公式インストール案内](https://pandoc.org/installing.html)を参照する。

```sh
python --version
pandoc --version
python scripts/validate.py
python scripts/build.py
```

WindowsでPythonコマンドが `py` の場合は `py -3 scripts/build.py` とする。HTMLを作る前にMarkdownの検査を行い、警告を残したまま公開しない。

## 表示の設計

本文は1行がおよそ45字になる幅（720px）、16px、行間1.8で組んである。各回の冒頭と末尾にある枠つきの行が前後の回へのリンクで、末尾には次回の題名を添えている。右上の「目次」から、全10回の一覧を開ける。ダークモードにも対応している。

## 事実と解釈の読み分け

本連載は、媒体固有性という理論の解説である。グリーンバーグ、レッシング、クラウスなどの議論の紹介と、各芸術の整理や作例の読みとの間には、解釈が含まれる。断定的に見える箇所も、定説というより一つの読みとして扱う。「第9芸術」などの番号は、フランス語圏の慣習による呼び名であり、芸術に優劣をつけるものではない。
