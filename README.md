# 媒体固有性で読む九つの芸術

全10回の連載記事です。Medium Specificity（媒体固有性）という美学理論を軸に、建築から漫画までの九つの芸術を順に読み解きます。

## 連載の狙い

- 各芸術が「何でできていて、何ができて、何ができないのか」を、媒体の条件から説明する。
- 芸術どうしの境界で何が起きているかを見る。
- 媒体固有性を、守るべき規範ではなく、作品や企画を分析する道具として使えるようにする。

各回は同じ三つの視点で進めます。

1. **媒体固有の条件**: その芸術は何に縛られているか
2. **固有の表現領域**: その縛りの中で何が可能になるか
3. **他芸術との境界**: 縛りを越えると何が起きるか

## 執筆・更新の規約

- ファイル名は `NN-slug.md`（`NN` は回の通し番号、slug は英小文字とハイフン）。
- 各記事は「リード → 三つの視点 → まとめ → 次回予告」の順で書き、末尾に前後の回へのナビゲーションを置く。
- 回の追加や並べ替えをしたときは、この目次と各記事末尾のナビゲーションを合わせて更新する。
- 変更はブランチを切って Pull Request で取り込む。
